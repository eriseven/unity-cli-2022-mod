# Timeline / Set Clip Timing

```powershell
unity command set_timeline_clip_timing --timeline Assets/Timelines/Intro.playable --track Camera --clip_index 0 --start 2.5 --duration 1.0
```

The optional `com.unity.timeline` package must be installed; use `--dry_run true` for validation without saving.
