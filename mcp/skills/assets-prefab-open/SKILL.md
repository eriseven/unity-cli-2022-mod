# Prefabs / Open Stage

```powershell
unity command open_prefab_stage --prefab Assets/Prefabs/Enemy.prefab
```

The referenced prefab must lie under the configured Pipeline authoring root. For unattended declarative changes, `save_prefab_contents` remains the preferred command.
